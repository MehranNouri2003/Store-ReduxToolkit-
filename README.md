# E-Commerce Store

A complete and modern e-commerce project focused on user experience, shopping cart management, and working with real-world data.

In this project, an online store has been implemented with features for displaying and managing various products and integrating with a real API. The shopping cart state is managed using `Redux Toolkit`, providing a structured and maintainable approach to adding, removing, and updating products.

## Tech Stack

* **Next.js** — Building the user interface and core project structure
* **Tailwind CSS** — Fast and responsive styling
* **REST API** — Fetching and managing product data
* **Redux Toolkit** — State and shopping cart logic management

## Features

* Displaying various products
* Fully interactive shopping cart
* Adding and removing products from the cart
* Updating product quantities
* Shopping cart state management with `Redux Toolkit`
* Fetching data from a real API
* Modern and responsive design with Tailwind CSS
* Built with Next.js

This project was built to practice and implement core concepts of e-commerce development, state management, and API integration.
